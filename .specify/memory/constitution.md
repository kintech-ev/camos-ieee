# ICAMC Website Constitution

1. One obvious place for each thing.
2. Keep the repository shallow and predictable.
3. `src/content.ts` is the source of truth for conference facts.
4. `src/styles.css` is the canonical visual system.
5. `/design-system` is the canonical rendered design reference.
6. Use Astro statically by default; add client JavaScript only for real interaction.
7. Do not invent conference information to fill layouts.
8. Pending details must be visibly marked as pending.
9. The NOMS 2027 website is a UX/information-architecture inspiration, not a source of copied branding or assets.
10. ICAMC branding and its Automation/Mobility/Connectivity identity remain primary.
11. Accessibility, keyboard operation, responsive layouts, and readable contrast are release requirements.
12. Prefer typography and spacing over excessive borders and card grids.
13. New directories require a demonstrated need.
14. Every common workflow has one obvious command.
15. `npm run check` is the release gate.
