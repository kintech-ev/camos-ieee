# Research and Reference Notes

## Primary reference

`https://noms2027.ieee-noms.org/` is the requested design reference.

The site blocks automated retrieval in the current implementation environment, so implementation must not claim pixel-perfect reproduction. The visual direction deliberately follows recognizable IEEE/NOMS conference-site conventions instead of inventing a startup-style landing page:

- institutional utility area
- logo/masthead separated from primary navigation
- strong blue navigation strip
- large location/conference hero
- information-dense homepage
- main-column + sidebar layout for author/administrative pages
- compact important-date/update panels
- tables and lists for organization and registration information
- restrained typography and shape language
- dark institutional footer

## Publicly verifiable NOMS 2027 context

Public announcements identify NOMS 2027 as an IEEE/IFIP Network Operations and Management Symposium in Montréal, Canada, 10–14 May 2027, with technical sessions, tutorials, demos, posters, panels and dissertation sessions. This context is used only to understand the type of conference information architecture; none of its event content is copied into ICAMC.

## ICAMC visual source

The existing ICAMC CFP provides the conference logo and established green/orange/blue semantic identity across Automation, Mobility and Connectivity. Its brochure layout is not used as the website layout.
